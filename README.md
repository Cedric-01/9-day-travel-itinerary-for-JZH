# 江浙沪9日旅游计划

这是一个用来分享与编辑个人旅游行程的仓库示例，基于 GitHub Pages + Jekyll 渲染，并在每篇行程页面内用 Leaflet + OpenStreetMap 显示交互地图。

快速使用说明：
- 新建行程：在 `_itineraries/` 下新建 `.md` 文件，参考示例的 front-matter（title / start_date / end_date / locations / photos）。
- 编辑：任何人可点击页面上的 `Edit`（或直接在仓库中编辑 `.md` 文件）来修改行程。
- 部署：在仓库设置 → Pages 中启用 GitHub Pages（Source: main / root），Jekyll 会自动构建并发布站点。

如果你希望我直接将这些文件提交到你新建的仓库，请在创建好仓库后把仓库的 owner/repo 发给我，我会替你提交并打开 Pages。
